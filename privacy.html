yt-stats-claude Privacy Policy

Last updated: October 17, 2026

Who uses it

yt-stats-claude is a private tool run by one person, the owner of the YouTube channel @beanjahmean, on their own computer. It signs in only to that owner's Google account. It has no other users.

YouTube API Services

This tool uses YouTube API Services. Use of it is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

  • The channel's own video list and details (titles, descriptions, tags, durations, publish dates).
  • The channel's own YouTube Analytics numbers (views, watch time, average view percentage, subscribers gained, likes, shares, comments).
  • Upload access, used only to upload the owner's own videos with their metadata.

How the data is used, stored and shared

  • Statistics are written to report files on the owner's computer so the owner can decide what to make next.
  • The sign-in token is stored only on the owner's computer.
  • Nothing is sent to any server other than Google's. No data is sold, shared with third parties, or used for advertising.
  • Stored API data is refreshed or deleted within 30 days.
  • This website itself sets no cookies and collects nothing.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. After revoking, the local token and reports are deleted from the owner's computer.
